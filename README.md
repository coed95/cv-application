# CV Application

A CV/résumé builder created with React as part of The Odin Project curriculum.

Users can enter their personal information, education, and work experience and see the resulting CV update dynamically.

## Features

- Add personal details such as name, email, and phone number
- Add multiple education entries
- Add multiple work experience entries
- Edit previously entered information
- Remove education and experience entries
- Live CV preview
- Controlled form inputs using React state
- Dynamic rendering of lists with unique IDs

## Built With

- React
- JavaScript
- CSS
- Vite

## Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Move into the project directory:

```bash
cd cv-application
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
